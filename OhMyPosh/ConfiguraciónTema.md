# COMO CONFIGURAR ASPECTOS DE TU TEMA

## Entra al archivo .json:
```
code ~/.poshthemes/[TEMA].omp.json
```

## Puedes añadir salto de linea:
```
"type": "prompt",
"newline": true
```

## Guarda los cambios con:
```
source ~/.bashrc
```

# ELIMINA EL TEMA ANTERIOR:

## Comandito:
```
rm ~/.poshthemes/aliens.omp.json
```

## Comprueba:
```
ls ~/.poshthemes/
```
